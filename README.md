# SPRIX Chemistry — Interactive Edition

منصة كيمياء مفتوحة للطلاب بدون تسجيل دخول أو لوحة مشرفين.

المحتوى مبني على فهرس كتاب **الكيمياء البكالوريا المصرية الصف الثاني الثانوي – الجزء الأول** المرفوع في المحادثة، مع تحويل المحتوى إلى تجربة تفاعلية: خريطة تعلم، غرف دروس، شخصيات وحوار، مختبر افتراضي، وساحة ألعاب.

## الهوية
تم استخدام صورة الشعارات التي رفعها المستخدم داخل `assets/`.

## ملاحظة مهمة
هذه النسخة تستخدم شخصيات مرسومة أصلية بأسلوب واجهة تفاعلية، وليست نسخًا من شخصيات QUREO/Sprix الأصلية. لإدخال الشخصيات الأصلية نفسها، أضف ملفاتها المرخّصة إلى `assets/` ثم نربطها بمكوّن الشخصيات.


## شخصية المنصة: كيمتشي
تمت إضافة الشخصية المرفوعة من المستخدم باسم **كيمتشي** كمرشد تفاعلي. يمكنه عرض الحوار، استقبال أسئلة الطالب، تشغيل النطق العربي عبر المتصفح، وإظهار حوار موجه داخل الدروس.
